## Deploy su GitHub Pages

1. Carica la cartella su un repository GitHub
2. Vai in **Settings → Pages**
3. Seleziona il branch `main` e la cartella `/ (root)`
4. Il sito sarà disponibile su `https://tuonome.github.io/new-studios`

## Tech Stack

- HTML5 / CSS3 puro — nessun framework
- JavaScript vanilla
- Font: Space Grotesk + Instrument Serif + JetBrains Mono (Google Fonts)
- Compatibile con tutti i browser moderni
